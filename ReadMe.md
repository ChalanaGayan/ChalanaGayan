## 🎓 Final Year Project — NeuraShield

> **Adaptive Real-Time Web Attack Classification using Continual Learning & LLM Explainability**

Modern web applications face rapidly evolving cyberattacks — SQL injection, XSS, OS command injection, SSRF, and more. Traditional detection systems struggle with catastrophic forgetting and lack explainability during model updates.

**NeuraShield** is our solution: an adaptive framework that combines:
- 🧠 **Hybrid Siamese architecture** with DistilBERT embeddings + handcrafted payload features
- 🔄 **Continual learning** — adapts to new attack patterns without forgetting old ones
- 🔍 **Novel attack detection** — identifies unseen attack types in the wild
- 💬 **LLM-based explainability** — explains classification decisions in plain language

**Results:** 97.80% baseline classification accuracy · 95.34% retained accuracy across 3 incremental learning phases
